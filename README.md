# Nexus Launcher

> A modern game launcher and library manager designed to bring your games from multiple platforms together in one place.

![Nexus Launcher](https://guardbyte.me/downloads/Nexus%20Launcher/nexusHeader3.png)

## 📖 About

Nexus Launcher is a desktop game launcher designed to provide a centralized location for managing and launching games from multiple game platforms.

The goal of Nexus Launcher is to make it easier to discover, organize, and launch your games without having to manually open each individual launcher.

---

## ✨ Features

- 🎮 Unified game library
- 🔍 Automatic game detection
- 🖼️ Game artwork and metadata
- 🚀 Launch games directly from Nexus Launcher
- 📚 Organize games by launcher
- ⚙️ Configurable launcher settings
- 🔄 Automatic updates
- 🧹 Cache and library management
- 🎨 Customizable interface
- 📦 Much more to come!
